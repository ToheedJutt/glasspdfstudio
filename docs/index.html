Why is there no “upload your PDF” button on this page? By design. GlassPDF Studio is local-first software: the studio runs on your own computer, so your files are never uploaded to anyone’s server — not even ours. This page is the project’s home; the app itself is one quick install away, below. Prefer to click around first? The live demo runs in your browser — it sleeps when idle, so give it a minute to wake up, and Office conversions and OCR run in reduced mode there. The full power is the local install.

Run it yourself

Needs Python 3.12+. On Windows, the repo’s Start GlassPDFStudio.bat does all of this for you.

git clone https://github.com/ToheedJutt/glasspdfstudio.git
cd glasspdfstudio/GlassPDFStudio
python -m venv .venv
.venv\Scripts\activate        # Windows (source .venv/bin/activate on Mac/Linux)
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5055 in your browser. Optional: install LibreOffice for layout-accurate Office conversions and Tesseract for OCR — without them the app still works and tells you exactly what is missing.
