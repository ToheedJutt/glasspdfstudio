Why is there no “upload your PDF” button on this page? By design. GlassPDF Studio is local-first software: the studio runs on your own computer, so your files are never uploaded to anyone’s server — not even ours. This page is the project’s home; the app itself is one quick install away, below. Or try the live demo first — it runs on a free server, so it may take a minute to wake up, and a few conversion tools run in reduced mode there.

The tools

Every tool below is built in and verified working.

Organize

  • Merge PDFs Combine several files into one
  • Split PDF By pages or page ranges
  • Compress PDF Shrink size with quality control
  • Rotate pages Fix sideways scans in seconds

Convert

  • PDF to Word, Excel, PowerPoint
  • Word, Excel, PowerPoint to PDF Layout-accurate via LibreOffice
  • HTML to PDF
  • PDF to PDF/A Archivable copy

Edit & secure

  • Edit PDF Add text and shapes onto pages
  • Watermark Custom text, position, opacity, color
  • Protect PDF Add a password
  • Unlock PDF Remove a password from your copy

Images

  • PDF to JPG Every page rendered as an image
  • JPG to PDF Including a scan-style mode

Run it yourself

Needs Python 3.12+. On Windows, the repo’s Start GlassPDFStudio.bat does all of this for you.

git clone https://github.com/ToheedJutt/glasspdfstudio.git
cd glasspdfstudio/GlassPDFStudio
python -m venv .venv
.venv\Scripts\activate        # Windows (source .venv/bin/activate on Mac/Linux)
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5055 in your browser. Optional: install LibreOffice for layout-accurate Office conversions and Tesseract for OCR — without them the app still works and tells you exactly what is missing.
